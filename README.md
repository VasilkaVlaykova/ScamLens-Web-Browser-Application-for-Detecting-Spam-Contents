# ScamLens

ScamLens is a web-based machine learning prototype designed to help detect suspicious SMS messages, phishing emails, and malicious URLs. The project explores the use of machine learning and NLP techniques to classify spam content, assess potential risks, and provide users with safety guidance before interacting with suspicious content.

The project includes:
- Dataset exploration and preprocessing
- Experimentation with machine learning algorithms
- Spam and phishing detection models
- Unicode spoofing / homograph detection research
- Streamlit-based prototype interface
- User-focused security awareness tips

ScamLens is being developed as both a research and practical cybersecurity project, combining machine learning experimentation with an accessible web application concept.
